هذا إصدار PWA يعمل كتطبيق ويب ويمكن إضافته إلى شاشة iPhone الرئيسية.
طريقة النشر المجانية المقترحة: GitHub Pages، بنفس فكرة التطبيقات السابقة.

الملفات المطلوبة للنشر موجودة كلها داخل هذا المجلد.
بعد نشر الرابط على GitHub Pages افتحه من Safari ثم مشاركة > إضافة إلى الشاشة الرئيسية.

البيانات محفوظة محلياً على الجهاز، ويمكن تصدير/استيراد نسخة احتياطية من داخل التطبيق.
